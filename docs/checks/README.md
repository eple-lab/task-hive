## 표기

- **확인함**: 공식 문서에서 직접 읽었다. 출처와 확인한 날짜를 적는다.
- **외부 자료**: 공식 문서가 아닌 곳(개발자 글, 이슈)에서 읽었다. 직접 실행해 확인해야 한다.
- **확인 못 함**: 문서에 없거나 실행해야 알 수 있다. [PoC](../poc/README.md)로 넘긴다.

가격·한도·정책은 바뀐다. 구현 직전에 같은 링크로 다시 확인한다.
