# Colab 이용 조건

확인한 날: 2026-11-17

## 1. 한 줄 결론

Colab은 **과제용 실험 환경**으로 쓴다. 목적은 LLM이 한국어 대화를 요약하고 할 일을 뽑을 수 있는지 확인하는 것이다(eple 확정, [D-13](../02-decisions.md)). 계속 켜 두는 서비스의 기반으로 쓰지 않는다.

## 2. 확인한 사실 (Colab FAQ)

| 내용 | 원문 요지 |
|---|---|
| GPU 종류 | 시간에 따라 달라진다. 특정 GPU를 보장하지 않는다 |
| 자원 | 보장되지 않고 무제한이 아니다. 사용 한도는 공개하지 않으며 바뀐다 |
| 실행 시간 | 보통 최대 12시간. 사용 패턴에 따라 다르다 |
| 유휴 | 쓰지 않으면 시간 초과로 끊긴다 |
| 금지 | 대화형 연산과 관련 없는 파일 호스팅, 미디어 제공, 웹 서비스 제공. 원격 프록시 연결 |
| 무료에서 종료될 수 있는 것 | SSH·원격 데스크톱 같은 원격 제어, 노트북 화면을 거치지 않고 주로 웹 화면으로 쓰는 것 |

출처: [Colab FAQ](https://research.google.com/colaboratory/faq.html)

## 3. Task Hive에 미치는 영향

- Colab에 LLM을 띄우고 ngrok으로 여는 구조는 위 제한 문구에 **해당할 수 있다.** 세션이 경고 없이 끊길 수 있다.
- 수업에서 `llm-chatbot`을 같은 방식으로 만들었다. 과제에서 모델을 직접 실행해 보는 용도로 쓴다.
- 과제 조건도 "GPU가 필요한 모델은 Colab 같은 무료 환경을 활용"이라고 안내한다.

## 4. 쓰는 범위 (확정)

| 쓰는 것 | 쓰지 않는 것 |
|---|---|
| LLM이 대화를 요약할 수 있는지 실험 | 여러 사용자에게 계속 제공하는 서비스 |
| LLM이 할 일을 뽑을 수 있는지 실험 | 사용하지 않는 동안 세션을 억지로 유지하기 |
| TTS·Whisper 모델 비교 실험 | 남의 데이터 처리 |
| 본인이 켜 두고 본인이 시연 | |

## 5. 설계에 반영할 것

| 항목 | 내용 |
|---|---|
| 끊겨도 동작 | Colab이 끊기면 대화만 "연결 안 됨"으로 안내하고 벌집·체크는 계속 된다 |
| 각자 자기 Colab | 사용자마다 자기 주소를 넣는다(D-04). 운영자의 Colab 하나를 여럿이 나눠 쓰지 않는다 |
| 안내 | README와 연결 화면에 "과제용 실험 환경, 세션이 끊길 수 있음"을 적는다 |
| 실험 기록 | 노트북에서 직접 돌린 결과(요약, 추출, GPU 메모리)를 [PoC](../poc/README.md)에 남긴다. 노트북 안에서 실행한 기록은 Colab의 본래 용도다 |
| 대안 | 업스트림을 "OpenAI 호환 주소"로 일반화해 두면 다른 실행 위치로 바꿀 수 있다. 지금은 만들지 않고 자리만 둔다 |
