# 규칙 (Business Rules)

앱이 지키는 규칙을 한곳에 모으고, **어디에서 막는지** 표시했다.

- **화면**: 사용자에게 빨리 알려 주는 편의용. 조작할 수 있으므로 이것만으로는 안전하지 않다.
- **백엔드**: 진짜 방어선. 화면을 거치지 않은 요청도 여기서 걸린다.
- **DB**: 마지막 안전망. 코드에 실수가 있어도 데이터가 망가지지 않게 한다.

## 할 일 등록

| 규칙 | 화면 | 백엔드 | DB |
|---|:-:|:-:|:-:|
| 제목은 비울 수 없다 | ✅ | ✅ | ✅ CHECK |
| 제목은 200자까지 | ✅ maxlength | ✅ | |
| 마감일은 필수 ("날짜를 등록해주세요.") | ✅ | ✅ | |
| 지난 날짜는 안 된다 | ✅ 달력 `min` + 검사 | ✅ | |
| 마감일 형식은 `YYYY-MM-DD` | ✅ date 입력 | ✅ | ✅ CHECK |
| 마감일 기본값은 오늘 | ✅ | | |
| 미완료 할 일끼리 같은 제목 금지 (대소문자·앞뒤 공백 무시) | | ✅ | |

- 완료된 할 일과는 같은 제목이어도 된다. "장보기"처럼 반복하는 일을 다시 등록할 수 있게.
- 이미 저장된 지난 날짜 할 일은 그대로 두고, 화면에서 빨간 글씨로 보여 준다.

## 태스크 등록

| 규칙 | 화면 | 백엔드 | DB |
|---|:-:|:-:|:-:|
| 태스크는 반드시 할 일 하나에 속한다 | ✅ 라디오 선택 필수 | ✅ | ✅ NOT NULL + FK |
| 완료된 할 일에는 추가할 수 없다 | ✅ 라디오 목록에서 뺌 | ✅ 409 | |
| 같은 할 일 안에서 같은 제목 금지 | | ✅ 409 | |
| 태스크 아래 태스크는 없다(한 단계만) | | | ✅ 표 구조 |

## 완료

| 규칙 | 화면 | 백엔드 | DB |
|---|:-:|:-:|:-:|
| 안 끝난 태스크가 있으면 확인을 받는다 | ✅ 확인창 | ✅ 409 + `force` | |
| 확인하면 남은 태스크도 함께 완료 | | ✅ 트랜잭션 | |
| 완료된 할 일의 태스크를 되돌리면 할 일도 미완료로 | | ✅ 트랜잭션 | |
| 되돌릴 때 같은 제목의 미완료 할 일이 있으면 안 된다 | | ✅ 409 | |
| 완료 여부와 완료 시각은 항상 짝이 맞는다 | | ✅ | ✅ CHECK |

확인창 문구: "완료하지 않은 태스크가 N개 있습니다. 그래도 완료하시겠습니까? (남은 태스크도 함께 완료됩니다)"

## 삭제

| 규칙 | 화면 | 백엔드 | DB |
|---|:-:|:-:|:-:|
| 태스크가 있는 할 일을 지울 때만 확인을 받는다 | ✅ 확인창 | | |
| 할 일을 지우면 태스크도 함께 지워진다 | | | ✅ ON DELETE CASCADE |
| 완료 후 90일 지난 할 일은 자동 삭제 | ✅ 삭제 예정일 표시 | ✅ 시작 시 + 6시간마다 | |

확인창 문구: "하위 태스크 N개도 함께 삭제됩니다. 삭제하시겠습니까?"

## 보기

| 규칙 | 어디서 |
|---|---|
| 검색은 할 일 제목과 태스크 제목 모두에서 찾는다 | 백엔드 (`LIKE`) |
| "오늘 할 일만"은 마감일이 오늘인 것만 | 백엔드 (서버 컴퓨터 기준 날짜) |
| 검색어 없이 "오늘 할 일만"인데 없으면 "오늘은 할일이 없어요 ^^" | 화면 |
| 정렬: 미완료 → 마감일 빠른 순 → 최근 등록 순 | 백엔드 |
| 오늘 마감은 노란 배경, 지난 마감은 빨간 글씨 | 화면 |
| 태스크를 넣을 할 일 목록(라디오)은 검색·필터와 상관없이 미완료 전부 | 화면 |

## 중간에 정한 것들

PRD에 없던 부분은 이렇게 정했다. 바꾸려면 [decisions.md](decisions.md)에 이유를 남기고 고친다.

- 강제 완료 시 남은 태스크도 완료 처리(할 일만 완료되고 태스크가 안 끝난 채 남는 어색한 상태를 막으려고)
- 마감일은 할 일에만, 태스크에는 없음
- 중복 비교는 대소문자와 앞뒤 공백을 무시
