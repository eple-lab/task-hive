# PoC-02. TTS 한국어 남·여 목소리

상태: 시작 전 · 관련: [D-03](../02-decisions.md), R-PANEL-2, [Q-13](../07-open-questions.md), [09 확인 기록 2.8](../09-verification.md)

## 1. 질문

Colab에서 돌릴 수 있고 **한국어 남·여 목소리를 모두 쓸 수 있는** TTS 모델이 있는가?

## 2. 왜 필요한가

- 요구사항이 "목소리 선택(남, 여)"이다.
- 2026-11-17에 모델 페이지를 확인했지만, 남·여 한국어 목소리를 둘 다 제공한다고 적힌 모델을 찾지 못했다.
- 없다면 대안(음높이 변환, 목소리 하나만 제공)을 정해야 한다.

## 3. 성공 기준 (실험 전에 적는다)

| 기준 | 숫자 (예시, 미확정) | 근거 |
|---|---|---|
| 남·여 목소리 | 한국어로 남 1개, 여 1개 이상 | R-PANEL-2 |
| 알아듣기 | 시험 문장 20개 중 18개 이상을 한 번에 알아듣는다 | eple이 듣고 판정 |
| 읽기 오류 | 숫자·날짜·영어가 섞인 문장 5개 중 4개 이상을 바르게 읽는다 | D-day, 날짜를 자주 읽는다 |
| 지연 | 한 문장을 1.5초 안에 만들기 시작한다 | [08](../08-performance-review.md) 목표 |
| 기준선보다 나은가 | 브라우저 내장 음성보다 듣기 좋다고 판정 | 기준선이 이기면 Colab TTS를 뺄 수 있다 |

## 4. 후보와 통과/탈락 조건

통과/탈락 조건:

- 한국어를 지원한다.
- 라이선스가 과제·데모 용도를 허용한다. 설치한 패키지의 LICENSE로 확인한다.
- Colab 무료 GPU(또는 CPU)에서 LLM과 함께 돈다.
- 남의 목소리를 허락 없이 복제하지 않는다.

| 후보 | 성격 | 지금까지 확인한 것 | 통과/탈락 |
|---|---|---|---|
| 기준선: 브라우저 내장 음성 | 기기에서 실행, 서버 없음 | 목소리가 기기마다 다르다. 에코를 걸 수 없다 | - |
| MeloTTS-Korean | 가벼운 전용 모델 | MIT. 예제에 한국어 화자가 하나만 나온다 | 화자 수 확인 필요 |
| Supertonic 2 | 기기용 초소형 (66M, ONNX) | 한국어 지원. 예제에 `M1` 목소리. 모델은 OpenRAIL-M | 목소리 수, 사용 조건 확인 필요 |
| XTTS-v2 | 목소리 복제형 | 한국어 지원. 참조 음성 6초. Coqui Public Model License | 라이선스 확인 필요 |
| Kokoro-82M | - | 한국어 미지원 | **탈락** |

## 5. 자료와 정답

- 시험 문장 20개 (`eval/samples/tts/`): 인사, 질문, 긴 문장, 숫자·날짜("11월 17일", "D-3"), 영어 섞인 문장("Task Hive"), 감정이 있는 문장.
- 정답: 문장마다 바른 읽기를 미리 적는다(예: "D-3" → "디 마이너스 삼" 또는 "사흘 전" 중 무엇으로 읽을지).

## 6. 절차

1. 후보마다 설치하고 LICENSE를 읽는다. 탈락 조건을 먼저 본다.
2. 한국어로 쓸 수 있는 목소리 목록을 뽑아 남·여를 센다.
3. 시험 문장 20개를 목소리마다 만든다. 걸린 시간과 GPU 메모리를 적는다.
4. eple이 듣고 판정한다. 누가 어느 모델인지 가리고 듣는 것이 좋다.
5. 남·여 목소리가 하나뿐인 모델은 음높이를 바꿔 다른 성별처럼 들리는지 따로 확인한다.
6. 저음·에코 효과(Web Audio)를 입혀 들어 본다.
