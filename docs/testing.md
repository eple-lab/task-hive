# 테스트

자동 테스트 코드는 아직 없다. 지금까지 확인한 방법과, 과제 제출 전에 직접 해 볼 체크리스트.

## 테스트할 때 진짜 데이터를 지키는 법

`DB_PATH`를 바꿔서 임시 DB로 서버를 켜면 `data/todo.db`를 건드리지 않는다.
```bash
PORT=3999 DB_PATH=./data/test.db node server.js
```
PowerShell이라면:
```powershell
$env:PORT=3999; $env:DB_PATH="./data/test.db"; node server.js
```
끝나면 `data/test.db`를 지우면 된다.

## 과제 확인 체크리스트 (길 A)

과제 평가 기준 "CRUD가 동작하고 앱을 껐다 켜도 데이터가 남는 장면"을 위한 순서.

- [ ] `npm start` → http://localhost:3000 열림
- [ ] 할 일 추가 → 목록에 나타남 (Create)
- [ ] 태스크로 등록 → 라디오로 할 일 선택 → 그 할 일 아래 나타남
- [ ] 새로고침 → 그대로 있음 (Read)
- [ ] 태스크 체크 → 진행률(1/2)이 바뀜 (Update)
- [ ] 안 끝난 태스크가 있는 할 일 체크 → 확인창 → 확인 → 남은 태스크도 완료, 오른쪽에 자동 삭제 날짜
- [ ] 할 일 삭제 → 태스크가 있으면 확인창 (Delete)
- [ ] 터미널에서 `Ctrl + C`로 서버 끄기 → `npm start`로 다시 켜기 → **새로고침해도 데이터가 남음** ← 캡처
- [ ] DB 뷰어로 `data/todo.db`를 열어 `todos`, `tasks` 표에 행이 있는지 확인 ← 캡처

## 규칙 확인 체크리스트

- [ ] 마감일을 지우고 추가 → "날짜를 등록해주세요."
- [ ] 달력에서 지난 날짜를 고를 수 없음
- [ ] 같은 제목의 할 일 두 번 등록 → "같은 이름의 할 일이 이미 있습니다."
- [ ] 완료된 할 일은 태스크 등록 라디오 목록에 안 나옴
- [ ] 검색창에 태스크 이름 → 그 태스크를 가진 할 일이 나옴
- [ ] 검색어 없이 "오늘 할 일만" + 오늘 마감 없음 → "오늘은 할일이 없어요 ^^"
- [ ] 제목에 `<b>굵게</b>` → 태그가 글자 그대로 보임

## API 테스트 기록

임시 DB로 서버를 켜고 Node 스크립트로 요청을 보내 확인했다.

| 시나리오 | 기대 | 결과 |
|---|---|---|
| 날짜 없이 할 일 추가 | 400 날짜를 등록해주세요 | ✅ |
| 지난 날짜 (2026-10-01) | 400 지난 날짜 | ✅ |
| 없는 날짜 (2026-02-30) | 400 형식 오류 | ✅ |
| 빈 제목 / 공백 제목 | 400 | ✅ |
| `" 장보기 "` 중복 (공백 차이) | 409 | ✅ |
| `Report` 다음 `report` | 409 | ✅ |
| 같은 할 일에 같은 태스크 | 409 | ✅ |
| 다른 할 일에 같은 태스크 | 201 | ✅ |
| 없는 할 일에 태스크 | 404 | ✅ |
| 안 끝난 태스크가 있는데 완료 | 409 + `open_tasks` | ✅ |
| `force: true` 완료 | 204, 태스크도 완료 | ✅ |
| 완료된 할 일에 태스크 추가 | 409 | ✅ |
| 완료 후 같은 제목 다시 등록 | 201 | ✅ |
| 그 상태에서 옛 할 일 되돌리기 / 그 태스크 되돌리기 | 409 | ✅ |
| 태스크 되돌리기 → 할 일도 미완료 | 204 | ✅ |
| 할 일 삭제 → 태스크도 삭제 | 204, 태스크 404 | ✅ |
| 91일 전 완료 → 서버 재시작 | 자동 삭제, 10일 전 완료는 남음 | ✅ |
| JSON 아닌 본문 / 숫자 아닌 id | 400 | ✅ |
| SQL 주입 (제목·검색) | 글자로 저장 / 0건 | ✅ |

## 화면 테스트 기록

브라우저에서 확인한 것: 등록·태스크 등록·완료 확인창·삭제 확인창·검색·오늘 필터·빈 목록 문구·새로고침 후 유지·XSS·연속 전송 방지(저장 중 두 번째 전송 무시)·좁은 화면(420px).

## DB 스키마 테스트 기록

메모리 DB에 `schema.sql`을 실행해 확인: 없는 할 일에 태스크(FK 거절), 빈 제목(CHECK 거절), 완료인데 완료 시각 없음(CHECK 거절), 잘못된 날짜 형식(CHECK 거절), CASCADE 삭제, 90일 삭제 쿼리, `schema.sql` 두 번 실행해도 에러 없음.
