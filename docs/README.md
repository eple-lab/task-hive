# Task Hive 문서

작성일: 2026-11-17 · 상태: 기획 단계 (코드 없음)

## 문서 읽는 법

- **확정**: eple이 답한 내용이다.
- **제안**: Claude의 추천이고 eple이 아직 정하지 않았다. 구현 전에 [07 열린 질문](07-open-questions.md)에서 정한다.
- **미검증**: 기억에 근거해 적었고 공식 문서로 확인하지 않은 내용이다. 구현 전에 확인한다.

## 용어

| 용어 | 뜻 |
|---|---|
| 태스크 | 벌집 한 칸에 해당하는 할 일. `todo` 프로젝트의 "할 일(Todo)"과 같다 |
| 하위 태스크 | 태스크 아래의 세부 항목. `todo` 프로젝트의 "태스크(Task)"와 같다 |
| 후보 | 대화나 캘린더에서 뽑았지만 아직 사용자가 고르지 않은 할 일 |
| 등록 예정 | 사용자가 벌집에 올리기로 고른 할 일. 아직 벌집에 없다 |
| 하이브 | 왼쪽 패널의 벌집 화면 |
| 상태창 | 오른쪽 패널 |
| 손님 | 구글 로그인 없이 이름만 적고 쓰는 사용자 |
| 업스트림 | 사용자의 Colab에서 ngrok으로 열어 둔 LLM·TTS 서버 |
