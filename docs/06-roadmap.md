## 1단계: 대화로 벌집 쌓기 (PoC)

목표: 입력(대화) → AI 처리(추출) → 결과(벌집)가 끝까지 이어진다.

| 묶음 | 내용 |
|---|---|
| 뼈대 | FastAPI, 정적 화면 3단 배치, 패널 접기, 테마, 메모리 저장소 |
| 손님 모드 | 이름 입력, 세션 쿠키, CSRF, 24시간 삭제, MD 내려받기 후 삭제 |
| 연결 | ngrok 주소·접속 키 입력, 주소 검사(SSRF 방어), 연결 확인 |
| Colab 노트북 | vLLM + TTS + 게이트웨이 + ngrok, 사용법 README |
| 대화 | SSE 중계, 다정한 말투 프롬프트, 외부 전송 안내, 첫 인사(시각·날씨) |
| 추출 | 후보 태스크·완료 신호 JSON 추출과 검증 |
| 상태창 | 후보, 등록 예정, 옮기기 버튼, 목소리 설정, 대화 설정 |
| 벌집 | SVG 벌집, 좌표 배정, 벌 비행·클로즈업, 꿀 채우기, 리스트 보기 |
| 태스크 규칙 | 등록·완료·삭제, 하위 태스크, 중복·길이 검사 (서버에서도) |
| 말하기 | Colab TTS, 에코·저음 효과, 브라우저 음성 대체, 토글 |
| 검증 | 가상 대화로 추출 정확도·시간 측정, 실패 사례 기록 |
| 테스트 | 기본 기능 → 보안 규칙(소유 검사, CSRF, 주소 검사, XSS) |

완료 기준:

- 다른 사람이 README만 보고 자기 Colab으로 실행해 대화 → 벌집 등록까지 할 수 있다.
- "그건 한 것 같아"로 체크박스가 체크된다 (하위 태스크 있는 경우·없는 경우).
- 검증 결과(기존 방식과의 비교, 실패 사례)가 문서로 있다.
- 테스트가 모두 통과한다.

## 2단계: 구글과 음성

| 묶음 | 내용 |
|---|---|
| 구글 로그인 | OpenID Connect, 가린 ID, 토큰 암호화, 탈퇴 |
| Neon | 표, RLS, 제목 암호화, 정리 작업 |
| 태스크 시트 | 한 방향 내보내기, "구글시트 가기" 버튼 |
| 캘린더 | 추가 동의, -7일 ~ +30일 읽기, 일별 체크박스, 전부 담기 |
| 일기 | 요약, "등록해 / 나중에", 시트·Docs 선택 저장, 최근 3일 요약 |
| STT | 마이크 버튼, Colab Whisper, 받아쓴 글을 입력창에 넣기 |
| 언어 | 화면 문구와 프롬프트의 언어 전환 |

완료 기준:

- 계정 두 개로 서로의 태스크가 보이지 않는다 (RLS 확인 스크립트).
- 캘린더 → 등록 예정 → 벌집이 이어진다.
- 일기가 사용자의 드라이브 폴더에 월별로 쌓인다.
- 말로 입력 → 대화 → 말로 답이 이어진다.

## 3단계: 운영

| 묶음 | 내용 |
|---|---|
| 배포 | `render.yaml`, Neon 운영 브랜치, 구글 리디렉션 주소 |
| 파이프라인 | PR 검사 전체(SAST, 의존성, 비밀값, SBOM), 브랜치 보호, 배포 후 점검 |
| 성능 화면 | 운영 지표 탭, PoC 검증 탭, 관리자 접근 제어 |
| 안내문 | 데이터 안내, (실사용자를 받는다면) 개인정보처리방침 |
| 점검 | `eple-security-check`, 구글 앱 검증 여부 결정 |

완료 기준: 데모 주소로 접속해 손님과 구글 사용자 흐름이 모두 동작하고, 보안 점검 기록이 있다.

## 4단계: 벌집 고도화 (초안 기능)

- Three.js 3D 벌집, 시작 연출(확대 → 포물선 → 둥둥)
- 확대·축소 (10%~200%)
- 칸을 꾹 눌러 위치 옮기기, 완료 태스크 가장자리로 옮기기
- 하단 입력창 직접 등록, 검색, 오늘만 보기
- 3D ↔ 리스트 전환 연출
- 구형 기기 성능 확인

## 5단계: 사업 모델 (초안 기능)

- 카카오 로그인, 카카오페이
- 월 3달러 구독, 첫 구독 15일 무료 연장(최초 1회), 미결제 시 정지·알림톡
- 무료는 7개까지, 등록·수정 시 5초 광고 (구독자는 광고 없음)
- 무료 사용자의 로컬 SQLite 암호화 저장, 구독 시 클라우드로 옮기기, 구독 취소 시 되돌리기
- 결제·환불·약관·사업자 관련 법적 검토 (이 단계 시작 전에 필요)
